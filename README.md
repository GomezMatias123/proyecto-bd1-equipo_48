# Proyecto para la materia Base de datos I 

Trabajo práctico del **Equipo 48** – 
**Motor:** SQL Express

## Descripción

Se trata de la creación, manipulación y mejora de una base de datos relacional para un emprendimiento de compra y venta como lo es **Dragabulk.TCG**, la descripcion del caso la podemos encontrar en `docs\etapa-1/descripcion-caso.md`.
